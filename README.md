# ИИ-помощник 1С

Расширение для 1С:Предприятие 8.3, которое встраивает ИИ-помощника (Claude или DeepSeek) прямо в базу.

## Возможности
- Чаты по дням с контекстом, ответ на сообщение, удаление сообщений и чатов
- Ответы по коду конкретной конфигурации со ссылками на модули и процедуры
- Обезличивание персональных данных (ФИО, телефоны, e-mail, ИНН, СНИЛС, карты) до отправки модели
- Правила базы, действующие во всех чатах; ответы только по 1С
- Создание внешних отчётов, обработок и расширений с проверкой синтаксиса и сборкой
- История изменений конфигурации, расширений, обработок и отчётов с подсветкой кода
- Справка по работе с помощником

## Состав
- `ext/` — исходники расширения 1С
- `ai-bridge.ps1`, `ai-common.ps1`, `ai-tools.cs` — мост между 1С и моделью (обмен файлами, обезличивание, сравнение версий)
- `ai-build.ps1`, `ai-registration.ps1` — сборка .epf/.erf/.cfe
- `ai-changes.ps1`, `repo-sync.ps1` — история изменений и хранилище конфигурации
- `setup.cmd` / `setup.ps1` — мастер установки
- `templates/` — шаблоны обработки, отчёта и расширения
- `deepseek/` — версия на DeepSeek API

## Установка
1. Установить платформу 1С 8.3.27+ и Claude Code (или получить ключ DeepSeek API).
2. Запустить `setup.cmd` и выбрать базу.
3. Запустить `ai-bridge.cmd`, открыть в базе раздел «ИИ-помощник».
