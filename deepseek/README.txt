ИИ-помощник 1С DeepSeek
=======================

Тот же ИИ-помощник для 1С:Предприятия, но ответы даёт модель DeepSeek через её API
(platform.deepseek.com), а не Claude. В базе появляется раздел «ИИ-помощник DeepSeek».
Помощник видит конфигурацию базы, её расширения, внешние обработки и историю хранилища
конфигурации и отвечает только на вопросы по 1С.

Чем отличается от версии на Claude
  - Нужен не аккаунт Claude, а ключ API DeepSeek; ответы оплачиваются по тарифам DeepSeek.
  - Расширение своё — ИИПомощникDeepSeek (объекты с префиксом ДС_), со своим каталогом обмена
    (<каталог базы>\ai-chat-deepseek) и своим мостом. Его можно ставить в ту же базу, что и версию
    на Claude: у каждой свой раздел, свои чаты и свой мост, они не мешают друг другу.
  - Поиск по выгрузке делает сам мост: модель вызывает инструменты glob, grep, read_file и list_dir,
    мост выполняет их в рабочей папке базы и возвращает результат. Выйти за рабочую папку нельзя.
  - Своих сессий у DeepSeek нет: на каждое сообщение мост отправляет переписку текущего чата
    (последние ~60 тыс. символов), поэтому удалённые сообщения модель сразу перестаёт видеть.

Установка
  1. Получите ключ API на platform.deepseek.com (раздел API keys) и пополните баланс.
  2. Запустите setup.cmd из этой папки:
     - мастер попросит вставить ключ API (символы не отображаются) и проверит его пробным запросом;
     - выберите базу из списка 1С, укажите пользователя-администратора и пароль;
     - мастер установит расширение. Если эта база уже подключена к версии на Claude
       (папка уровнем выше), готовая выгрузка конфигурации копируется оттуда — это быстрее.
  3. Откройте базу в 1С:Предприятии и нажмите раздел «ИИ-помощник DeepSeek».
     Если 1С напишет, что расширение работает в безопасном режиме, снимите у ИИПомощникDeepSeek
     флажок «Безопасный режим» в списке расширений и перезапустите 1С.

Мост
  ai-bridge.cmd в этой папке, окно «ИИ-помощник 1С DeepSeek — мост». Мастер ставит его
  в автозагрузку. Запускайте мост именно из этой папки: мост версии на Claude обслуживает
  только свой раздел.

Настройки (deepseek.json в этой папке)
  apiKey  — ключ API (хранится открытым текстом, в архив пакета не попадает);
  model   — модель, по умолчанию deepseek-chat;
  baseUrl — адрес API, по умолчанию https://api.deepseek.com.
  После правки файла перезапустите мост.

Персональные данные
  Как и в версии на Claude: ФИО, телефоны, e-mail, ИНН физлиц, СНИЛС, паспорта, номера карт
  и счетов, авторы версий хранилища заменяются метками до отправки в DeepSeek и подставляются
  обратно в ответ. Таблица соответствия — только на этом компьютере (private\<база>\pii-map.txt).
  Код конфигурации при этом отправляется в DeepSeek — учитывайте это для закрытых доработок.

Создание обработок, отчётов и расширений
  Как в версии на Claude: попросите в чате сделать или изменить внешнюю обработку, отчёт или
  расширение. Модель пишет исходники инструментом write_file (только в workspaces\<база>\output),
  вызывает build — мост проверяет синтаксис модулей и собирает .epf, .erf или .cfe в папку
  «Готовые файлы\<база>». Путь к файлу — в конце ответа. Основную конфигурацию помощник не меняет.
  Готовые файлы устанавливаете вы сами — сначала лучше на копии базы.

История изменений базы
  Как в версии на Claude: кнопка «История изменений» и вопросы в чате — кто, когда и что менял
  в конфигурации, расширениях, внешних обработках и отчётах (по выгрузкам и журналу регистрации).

Всё остальное (чаты по дням, ответ на сообщение, удаление, правила базы, хранилище) работает
так же, как в версии на Claude — см. README.txt уровнем выше.
